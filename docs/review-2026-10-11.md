# October 11 review implementation

The review preserves existing account data, the deployment pipeline and the
navy/gold theme. No new paid service or calendar integration is introduced.

## Editable choices

- Partial employment months use configured workdays; travel allowance and
  social contribution base follow the same proportion. Calendar-day division
  and a full travel allowance are editable alternatives.
- Vacation accrues monthly at annual entitlement / 12, prorating partial
  months and respecting employment start/end. Annual upfront entitlement is
  an alternative. Missing logs are separate from confirmed hours deficits.
- Trip departure and return each receive a full per-diem day initially, with
  editable fractions. Same-day trips count once. Rates remain manually editable.
- The backup screen is explicitly Export and Backup. JSON/CSV export remains
  available; automatic import is not advertised. Binary files are separate.

## Visible changes

New accounts have neutral financial/goal data and a skippable five-step setup.
Saved contracts are preserved; previous implicit personal defaults are captured
once for existing accounts. Employment dates are entered by the user.

The compact overview includes Work, Tasks, Water, Nutrition and Car. Images
and text occupy separate columns, and mobile navigation stays at the viewport
bottom. Fuel entry defaults to Trip A, with odometer entry as an advanced
alternative. Partial refills accumulate until the next full refill; estimated
driving range never substitutes for distance actually travelled.

Creatine settings move to Notifications. Account reminder rules and this
device's Push connection are distinct. Water chart pacing is separate from
reminder scheduling. Events offer ten predefined colors plus advanced custom
color selection. Documents include dates, payslip months and trip links;
uploads/downloads support 10 MB through private 1 MB chunks.

## Verification

29 unit tests cover calculation and existing domain behavior. Browser tests
cover registration, account isolation, task changes, work/leave/trips, exports,
device status, browser uploads and byte-perfect 10 MB file transfer. Layout
checks include 320, 375, 390, 430, 507, 834 and 1440 px. A local transaction
checks migration preservation and repeated-deployment behavior, then rolls back.
TypeScript and the optimized Webpack production build pass.

Viewport checks use browser emulation. Physical iPhone/iPad Push delivery
has not been verified by these tests.
